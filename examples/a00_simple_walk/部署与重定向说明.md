# A00 简单行走部署约定

- 策略输入 observation：490 维；history=5，term-major 顺序：`base_ang_vel(3), projected_gravity(3), command(3), phase(2), joint_pos(29), joint_vel(29), actions(29)`。
- 策略输出：29 维，单位 rad，关节顺序严格采用 profile 中的 right leg(6) → left leg(6) → waist(3) → left arm(7) → right arm(7)。手指不进入策略。
- 控制频率 500 Hz，策略频率 50 Hz，gait period 0.6 s。SuperMimic/LAFAN 重定向数据需先转成上述 29 关节顺序，再按 profile 的 default pose/action scale 归一化。
- 第一阶段只做平地直行：腿部使用重定向轨迹，腰部小幅跟随，双臂保持 nominal pose；先在 MuJoCo 验证足底接触、膝关节限位和力矩饱和，再接 CAN。
- 真机启动前运行 `validate_config_only:=true`；策略节点打开 CAN 后不要同时启动 `jljwholebody_bringup` 的 ros2_control。
